# 💰 Vyaya ET (Expense Tracker)

An intuitive, lightweight web application designed to help users record, categorize, and seamlessly manage their daily expenses. *“Vyaya” (व्यय) means expense in Marathi.* 

This project was built to solve the practical challenge of personal budgeting by offering a clean user experience backed by robust data management.

---

## 🚀 Key Features

*   **Secure Expense Logging:** Add, view, and organize daily expenditures instantly.
*   **Smart Categorization:** Group costs to quickly figure out where your money goes.
*   **Relational Storage:** Relies on a strict data schema to prevent duplicate logs or missing values.
*   **Responsive Interface:** Fully optimized for seamless tracking on both desktop and mobile screens.

---

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3 (Modern Responsive UI), JavaScript (ES6+)
*   **Backend:** Python
*   **Database:** PostgreSQL 

---

## ⚙️ Core Architecture & Logic

The project is structured with a strong focus on backend reliability and database integrity:
*   **Backend Layer:** Written in Python to handle request routing, input validation, and business logic cleanly.
*   **Data Layer:** Utilizes PostgreSQL to run secure relational queries, ensuring historical financial records remain accurately logged and safe.

---

## 🏁 Getting Started

### Prerequisites
Make sure you have the following installed on your machine:
*   Python 3.x
*   PostgreSQL Database Server

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd Vyaya
   ```

2. **Configure the Database:**
   * Create a new database in PostgreSQL named `vyaya_db`.
   * Set up your credentials inside your local configuration script.

3. **Run the Application:**
   ```bash
   python app.py
   ```
   *(Note: Update this step if your main script uses a different entry filename, like main.py or run.py)*
